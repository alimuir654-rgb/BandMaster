# Owner-supplied Figma game UI kits — source triage (27 October 2026)
**Scope:** visual inspiration and technical component analysis for the one-screen recruitment quality experiment. No purchase, import, activation, external runtime dependency or merge. This is **not verification of component contents**.

## Three supplied Community entries
1. **[Games UI/UX Elements Library 10,000+ — econev](https://www.figma.com/community/file/1401135710750637762/games-ui-ux-elements-library-10-000-by-econev)**. Third-party visual showcases exist at [Jack Conev's Dribbble](https://dribbble.com/shots/24620530--Games-UI-UX-Elements-Library-10-000-by-econev). **Conceptual priority: medium–high**. Study the discipline of *small cohesive game-specific control families*: role tabs, musician dossiers, counters, selection states, sliders/meters and recruiting action. The library advertises a large catalogue; its exact 10k component count, editable variant coverage, commercial reuse licence and price are not independently verified. Never combine multiple unrelated styles from a grab bag in the same game scene.
2. **[Interactive Game UI Button with Pattern](https://www.figma.com/community/file/1365225043097644885/interactive-game-ui-button-with-pattern)**. **Conceptual priority: high for one experiment**. Based on its listing title, likely a focused interactive patterned-button example; the actual file is inaccessible for direct component inspection. If the user can access it, inspect hover, active, pressed, disabled, focus, touch and label legibility. Use Figma's official [interactive component tutorial](https://help.figma.com/hc/en-us/articles/20953528101783-Design-an-interactive-button-component) as a VERIFIED method for variant states. Translate the pattern to **original BandMaster source-backed texture art and native Godot TextureButton**, not a screenshot or community assets without explicit game-distribution permission.
3. **[Game UX Kit](https://www.figma.com/community/file/1460785931676185568/game-ux-kit)**. **Conceptual priority: high for flow and information hierarchy**. We can only validate the URL/title, not the internal contents. Review for genre-first → browse musicians → compare six stats/biography → recruit into 3–6 person roster → name band LAST, keyboard/controller/mobile states and progressive disclosure. Prefer a whole-flow reference over just decorative buttons.

## Access/rights: treat as unresolved
- Figma Community pages directly block automated public retrieval; specific assets, authors of links 2–3, style previews, pricing, variants and file contents **were not confirmed**. Previous connected Figma Starter MCP calls reached account plan limits. We can review creator-supplied screenshots/preview copies, but should not claim to have inspected the files.
- Figma explicitly says [community licensing varies by file and paid/free status](https://help.figma.com/hc/en-us/articles/360038510873-Duplicate-Community-files). Its [Community Free Resource License](https://www.figma.com/legal/community-free-resource-license/) (where it applies) restricts use to the Figma platform and generally bars modifications/derivatives; *being free to open is not proof of permission to export assets into a commercial game*. Check the exact per-item terms or obtain a separate creator licence before shipping anything. Do not infer blanket commercial usage from public Community listing.
- [Figma interactive components](https://help.figma.com/hc/en-us/articles/360061175334-Create-interactive-components-with-variants) can provide practical inspiration for a five-state texture-back design in Godot without copying the community pack.
- No Figma plan upgrades, licence payments, Spine/DragonBones purchases, or unapproved commercial assets.

## Explicit sprint application
**00:00: art selection** — compare these three *approach categories* against the accepted recruitment reference; choose ONE restrained British-music art direction, not Frankenstein elements. Have a credible portrait/candidate story occupying the main screen before worrying about transitions. 
**02:00: control cohesion** — take only a small **five-control contract**: role tab, browse transport, candidate selection, six-stat physical indicator, recruit CTA. Define graphic states and consistent textures, label hierarchy and lighting. Candidate biographies and portrait art must be original or rights-cleared.
**04:00: Godot proof** — native 1280×720 and 390×844 screenshot render, states and constraints; inspect actual PNG and five-second comprehension with side-by-side approved reference, not just CI pass.
**06:00: stop/go** — explain whether the interface art is visibly improved, source rights still unresolved, and whether further dedicated artist work is needed. Never claim visual approval without owner assessment.

**Practical decision:** These sources are valuable as an inspiration and system-design benchmark, not a reason to restart Figma editing with a rate-limited account or to install large uncurated packs. Quality comes from *consistent component art and a coherent screen*, not quantity.
