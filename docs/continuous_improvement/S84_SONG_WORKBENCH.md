## One concrete experience

The primary object is the same song leaf throughout: actual title, two editable lyric lines, a refrain marker and a verse/chorus sketch. The actual selected leader offers a **new authored seed**, the player types/tries it, an actual other member supplies a supported written note, and the player can keep, rewrite or adopt an alternate before the original one-day session. Later visits reopen the same words, chosen refrain and unresolved note. No audio, semantic lyric scorer, new performance artwork or universal best choice is introduced.

Only **Lyric / Verse–Chorus**, starting a new original at progress0 with an empty canonical draft, enters this pilot. Riff/Groove/other forms and already-progressing legacy drafts retain their existing route. A legacy draft has no recorded fragment: do not manufacture earlier words or seed history for it. A new project's title and future session leader may still change explicitly, as the original Workshop permits; changing idea/form away from this pilot requires explicitly archiving the known workbench before using the old route.

## Exact types and common results

All Dictionary keys defined here are Strings. Exact token/request key sets are checked; unknown extension keys on stored source state are preserved. All returned state/material/context values are deep copies; callers cannot mutate the model through a returned alias. Failure/no-op never partially changes the supplied source. Pure functions never save, dispatch a paid Game action or call Story/Life/Calendar/Finance apply functions.

`Opening` means the actual complete `OpeningState.snapshot()`, including root and game unknown extensions, roster unknown fields, identity, audition wrapper and career. `Career` is its actual `game.career`. `Material` is `{lines:[{id:"hook:1",text:String},{id:"hook:2",text:String}],refrain_line_id:String,sections:{verse:String,chorus:String}}`; section values are actual stable line IDs. `MaterialPayload` is exactly `{text:String,refrain_line_id:String}` from the local editor, validated to the same two literal nonblank lines. CRLF is normalised to LF at the explicit boundary; case, punctuation and other actual line characters are retained. One trailing third empty line remains invalid rather than silently removed. The existing native local editor can temporarily contain incomplete input.

`Token` is exactly `{source_hash:String,wrapper_hash:String,project_id:String,wrapper_revision:int,fragment_revision:int,stage:int}`. `source_hash` fingerprints the current complete Opening after removing ONLY `game.career.song_workbench_v1`; `wrapper_hash` fingerprints the complete present raw wrapper, or the explicit absent marker. The other five values are validated against that actual source. The persistent project does not store this whole-career hash. Small-whole/integral-boundary/fraction/safe-integer handling is the existing precise S83 canonical policy, not JSON's default lossy display. Unknown/future/unsafe source cannot authorise an action just because a hash can be made.

`Mutation` is exactly `{ok:bool,changed:bool,state:Opening,message:String}` on both success and failure. Failure returns an exact deep copy of the input Opening with `changed:false`. A successful exact no-op also returns the unchanged source and `changed:false`. Owner results are `{ok:bool,changed:bool,message:String,view:Dictionary,expected:Dictionary}`; these never expose an internal mutable snapshot. On failed save, view/expected describe the exact restored current owner. A managed paid begin has the additional ephemeral transaction fields specified below.

The wrapper retains v1 bounds: one current project/current/prior/authored alternate, up to three notes and three paid receipts. Add a stable `fragment_id`, formed from the actual project ID plus fragment revision, and an explicit original-ID counter binding read from `Career.songs`. Do not infer this counter from catalogue length. Known incompatible binding can be explicitly archived while preserving all current source; malformed/future wrappers remain retained and held. Missing wrappers and already-progressing legacy drafts never acquire invented material/history.
