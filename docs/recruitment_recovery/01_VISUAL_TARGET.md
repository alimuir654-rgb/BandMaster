# One-screen visual target — production composition brief

## Working product statement

*Livin' The Dream* opens a battered physical band-recruitment case: backstage photographer's contact sheets, handwritten annotations, authentic documentary portraits, lived-in metal and paper, understated amber lamps and premium studio-grade controls. It is neither a generic dark SaaS dashboard nor a comic-book toy.

## Desktop / landscape: mandatory 1280×720 native proof

Distinct anchored regions (guides, not hardcoded percentages):

- **Genre/role identity:** upper/left frame, context visible within five seconds.
- **Candidates:** six browseable identity entries / source-specific headshots, each clearly different. Never use repeated faces under new names.
- **Hero:** dominant musician portrait, visually memorable, not postage-stamp or a cropped avatar.
- **Attribute board:** six red→amber→green inert meters directly beneath portrait, with legible native text and current values.
- **Dossier:** off-white authentic paper with meaningful strengths, friction, prior bands, ambition and trouble; legible body copy, not distressed to illegibility.
- **Action/dock:** tactile amber recruit action, clear price, remaining talent, existing lineup; action never hidden under decorative chrome.

Composition should read as **one physical object**. Rivet/stamp details must not dominate the character. Maintain a single directional light, consistent shadow scale, credible material thickness, controlled highlight contrast and actual whitespace.

## Phone: mandatory 390×844 native proof

Create a **separate mobile composition**, not a compressed desktop screenshot. First view must show: current musician identity/role, hero image, 6 comparable stats, cost and talent, a >=44 physical-pixel recruit action and role/candidate navigation. Rich dossier is a deliberately paged/scrollable linked paper layer. The bottom roster has a stable position; avoid obscuring primary action.

## Characters (two only in art-first milestone)

- One British grassroots front-person whose character reads immediately without a name.
- One contrasting potential recruit, different facial structure, styling, pose and personality, **same photographic or illustration language**.
- Human-referential natural anatomy and expressive uneven details; no generic clip-art eyes or face template, no glossy synthetic fashion portrait, no stylisation that conflicts with the band's setting.
- Do not fabricate consent, model release, a photographer or a licence. If fully original generated character art is used, explicitly label how it was generated and source/reuse review status; do not call it a human photo.

## Explicit anti-targets

- More low-detail code-authored SVG heads.
- Entire flattened UI image with invisible tap rectangles.
- Unlicensed/incorrectly labelled photographs or repeated faces.
- Cheap stock gradients posing as aged aluminium, noisy cork, black voids, disconnected cards, three unrelated design styles.
- Tiny meter captions, automatic phone scaling that damages hierarchy, fictional model values.

## Evidence and benchmark review

A generated *design target* is **not** acceptance. Keep both full-resolution rendered target and native Godot capture, labelled, side by side. Assess region-by-region against `docs/RECRUITMENT_REFERENCE_LOCK.md`.
