# S04 purpose-built tour craft assets

All 21 SVG textures are **original authored procedural vector artwork** (not photography). Four independent physical-purpose families (`venue`, `route`, `seal`, `commit`) each have `idle`, `hover`, `pressed`, `selected`, `disabled` states. SVGs are imported by Godot 4.7.2 as native Texture2D assets. Captions, prices, van health, venue names and booked day are **native GDScript labels**, not baked artwork. State differentiation uses paper light, metal and ink; selected retains texture on hover. The map is a **schematic decorative drawing**, not a geographical route/distance claim. Photographic cork from `Art/Photography/Formation/corkboard_day_pexels.webp` retains separate source/license/SHA manifest. `Art/Backgrounds/shared/home.webp` is an existing repo-backed photo stand-in, not represented as a new photograph of a tour van. Final owner material approval remains open; S07 pin/cork correction applies to formation and any inherited surfaces.
